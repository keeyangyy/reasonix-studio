## 改动

给远程主机加「逐台停用（不拨号）」与「只在侧栏隐藏」两种能力。

- **停用**（本机配置，对所有人/所有窗口生效）：`POST /remotes/open` 直接以 `remote.disabled` 拒绝；侧栏不再列出；设置页保留该行以便启用回来。
- **隐藏**（本窗口显示偏好）：前端本地偏好 `state/remotehide.ts`，按机器名记录、存 localStorage、跨重启保留，**不进配置文件**。
- **控件形态改了两轮**：文字按钮 → 与其它设置项一致的开关 → **行内只留一个开关**（「启用/停用」）；「在侧栏显示」移进该主机的编辑面板，且只在编辑已有主机时出现。

## 动机

机器多了以后：连不上的远端机器一直占着侧栏；某台只是暂时不用又不想删配置。两者语义不同——**停用是本机配置，隐藏是窗口偏好**。

## 取舍

- **字段写成 `disabled` 而不是 `enabled`**：缺省即启用，字段出现之前写下的主机条目仍照旧可用，不需要迁移。
- **隐藏做成前端本地偏好、不进配置文件**：它是窗口偏好，写进配置会污染"什么算配置"的语义。
- **行内只留一个开关**：同一行并排两个开关（左停用=本机配置、右显示=窗口偏好）读起来像重复；且原来常显的「启用」是动词、与状态词不一致。
- **被否决的方案（上游 #12203）**：我曾把"停用的主机也从侧栏拿掉"与"隐藏开关塞进编辑表单"作为上游 PR 提交，维护者明确 **#11991 定下的两条行为不变**——① 停用的机器**留在侧栏**（"机器离线不代表这个窗口该怎么显示"）；② 隐藏开关保持**行内即时动作**。上游一条都不收，本线按自己的取舍保留这两处。
